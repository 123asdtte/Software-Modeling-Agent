# PPT 智能生成 Agent · PRD（辅助教学）

> 版本：v0.1 ｜ 方向：辅助教学 ｜ 优先级：P0 ｜ 状态：待开发

---

## 1. 功能概述

教师输入课题与课时要求，AI 自动生成结构化 PPT：大纲 → 分页内容 → 可下载 PPT 文件 → 讲课备注。减少教师重复排版劳动。

## 2. 用户与场景

| 用户 | 场景 |
|---|---|
| 教师 | 备课做课件（软件工程 / UML 建模等课程） |
| 教师 | 公开课 / 汇报演示材料快速出稿 |

## 3. 输入输出

**输入**（示例）：
- "生成《软件工程 UML 建模》90 分钟课程 PPT"
- 可选参数：课时、面向年级、课程章节、风格要求

**输出**：
1. PPT 结构（大纲）：首页 / 课程目标 / 知识讲解 / 案例分析 / 课堂互动 / 练习任务 / 总结；
2. PPT 文件（.pptx，可直接打开编辑）；
3. 讲课备注（每页讲解要点、时间分配建议）。

## 4. 处理流程

```
输入课题 + 参数
  ↓
课程大纲生成（LLM：按教学法组织结构）
  ↓
分页内容生成（逐页：标题/要点/案例/互动）
  ↓
PPT 文件生成（python-pptx 工具）
  ↓
讲课备注生成
  ↓
输出（大纲 + pptx + 备注）
```

## 5. 功能需求

| 编号 | 需求 | 验收要点 |
|---|---|---|
| PPT-1 | 大纲生成 | 结构完整，含首页/目标/讲解/案例/互动/练习/总结 |
| PPT-2 | 分页内容 | 每页内容与课时匹配，90 分钟默认 18–22 页 |
| PPT-3 | 文件生成 | 生成可编辑 .pptx，版式规范，中文不乱码 |
| PPT-4 | 讲课备注 | 每页含讲解要点与建议时间 |
| PPT-5 | 教学案例 | 自动插入与主题匹配的教学案例（如用例图示例） |
| PPT-6 | 二次编辑 | 大纲可人工调整后重新生成，支持迭代 |

## 6. 边界与例外

- 图片素材：v13 先支持文字 + 结构图（UML 图可调用 UML Agent 生成后嵌入）；
- 超过单次生成容量（如 60+ 页）：分段生成并提示；
- 生成失败（模型超时）：保留大纲，允许重试单页。

## 7. 验收标准

- 90 分钟课题生成 ≤ 60s；
- 生成的 .pptx 可打开、可编辑、无乱码；
- 大纲结构命中 7 要素（首页/目标/讲解/案例/互动/练习/总结）；
- 至少 1 个教学案例自动插入。

## 8. 依赖

- PPT 生成工具 `app/tools/ppt_generator.py`（python-pptx）；
- 大纲/内容生成链 `app/chains/generation_chain.py`；
- UML 图嵌入（可选，接入 UML Agent）。
