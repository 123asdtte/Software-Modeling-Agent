# 教案智能生成 Agent · PRD（辅助教学）

> 版本：v0.1 ｜ 方向：辅助教学 ｜ 优先级：P0 ｜ 状态：待开发

---

## 1. 功能概述

教师输入课题，AI 自动生成完整教学设计（教案），符合学校教学文档规范，可直接使用或二次修改。

## 2. 用户与场景

| 用户 | 场景 |
|---|---|
| 教师 | 日常备课写教案 |
| 教师 | 公开课 / 检查评估需规范教案 |

## 3. 输入输出

**输入**（示例）：
- "生成《用例图》教学设计"
- 可选参数：课时、班级层次、教学法偏好

**输出**（结构化教案）：
课程名称 / 教学目标 / 教学重点 / 教学难点 / 教学流程 / 教师活动 / 学生活动 / 课堂练习 / 课后任务

## 4. 处理流程

```
输入课题
  ↓
教学目标生成（知识/能力/素养三维目标）
  ↓
重点难点识别
  ↓
教学流程设计（导入→讲解→案例→互动→练习→小结）
  ↓
师生活动拆分 + 课堂练习 + 课后任务
  ↓
输出教案（结构化文档）
```

## 5. 功能需求

| 编号 | 需求 | 验收要点 |
|---|---|---|
| LS-1 | 三维目标 | 含知识/能力/素养目标 |
| LS-2 | 重点难点 | 结合教材与学情合理识别 |
| LS-3 | 流程完整 | 导入/讲解/案例/互动/练习/小结齐全 |
| LS-4 | 师生活动 | 每个环节拆分教师活动与学生活动 |
| LS-5 | 练习与作业 | 课堂练习 + 课后任务各 ≥ 2 题 |
| LS-6 | 输出格式 | 结构化 Markdown，可导出 Word/PDF |

## 6. 边界与例外

- 教案为**辅助初稿**，必须教师复核；页面标注"AI 生成，请教师审核后使用"；
- 涉及具体教材页码/课时分配的，教师可二次指定；
- 学科敏感内容（思政、评价用语）遵循学校规范，生成后需人工把关。

## 7. 验收标准

- 生成的教案包含全部 9 个必填字段；
- 三维目标完整；流程环节 ≥ 5 个；
- 课堂练习与课后任务各 ≥ 2 题且与课题相关；
- 可一键导出 Word/PDF（供提交存档）。

## 8. 依赖

- 教案生成链 `app/chains/generation_chain.py`；
- 教案 Prompt `app/prompts/teacher_prompt.py`；
- 导出能力（Markdown → docx，可复用 Word 工具链）。
