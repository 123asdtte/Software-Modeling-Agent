# 智能问答 Agent · PRD（辅助教学）

> 版本：v0.1 ｜ 方向：辅助教学 ｜ 优先级：P0 ｜ 状态：待开发

---

## 1. 功能概述

基于教材知识库，为师生提供专业领域智能问答。回答须结合学校教材内容，做到"答得准、讲得懂、能落地"。

## 2. 用户与场景

| 用户 | 场景 |
|---|---|
| 学生 | 课前预习提问、课后复习答疑、作业卡点求助 |
| 教师 | 备课查证、教学素材检索、知识点讲解参考 |

## 3. 输入输出

**输入**：用户问题（自然语言）
- 例："什么是用例图？"
- 例："参与者（Actor）和角色（Role）有什么区别？"
- 例："include 关系和 extend 关系怎么区分？"

**输出**（结构化回答）：
1. 概念解释（结合教材定义）；
2. 通俗案例（类比/示例，如"用例图类似电影剧本：演员=参与者，剧情=系统功能"）；
3. 教材关联（引用教材章节/页）；
4. 实践建议（怎么用、常见误区）。

## 4. 处理流程

```
用户问题
  ↓
意图识别（是否知识问答类；非问答路由到其他 Agent）
  ↓
教材知识库检索（RAG：向量召回 + 重排）
  ↓
生成回答（LLM 结合检索片段，必须引用来源）
  ↓
输出 + 来源标注
```

## 5. 功能需求

| 编号 | 需求 | 验收要点 |
|---|---|---|
| QA-1 | 教材知识库问答 | 回答内容能在教材中找到依据 |
| QA-2 | 来源标注 | 每条回答标注引用章节/文档 |
| QA-3 | 无命中兜底 | 知识库未命中时明确说明，不编造 |
| QA-4 | 多轮追问 | 支持 3 轮内上下文追问（同一会话） |
| QA-5 | 教学用语友好 | 回答面向师生，避免纯学术黑话，必要时给类比 |

## 6. 边界与例外

- 超出教材范围的问题：说明"该问题不在当前教材知识库范围内"并给出建议方向；
- 敏感/无关问题：礼貌拒绝并引导回学习场景；
- 教材冲突/过时内容：以最新教材版本为准，标注"以教材 X 版为准"。

## 7. 验收标准

- QA 评测集（≥30 问）top-3 检索命中率 ≥ 90%；
- 回答正确率（人工评分）≥ 85%；
- 引用可追溯率 = 100%（每条回答都带来源）；
- 无命中兜底触发时不得出现编造内容。
