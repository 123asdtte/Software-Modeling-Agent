> 项目名：AI教学智能体平台 v13
> 技术路线：Python + LangChain（全新自研，不依赖 v12 代码，不迁移扣子工作流）
> 展示对象：陈老师 / 任总 / 董事长
> 文档版本：v0.1（初稿）｜ 编写：罗智峰

---

## 1. 项目背景

当前学校教师和学生存在痛点：

**教师**
- 课程资料制作耗时；
- PPT 制作重复劳动；
- 教案编写效率低；
- 教学资源整理困难。

**学生**
- 专业知识理解困难；
- 缺少即时答疑；
- 建模实践缺少指导。

**结论**：建设一个面向高校教学场景的 AI 智能体平台——为教师提供教学生产力工具，为学生提供学习辅助工具。

## 4. 核心能力简介

### 4.1 智能问答 Agent（辅助教学）
基于教材知识库，为师生提供专业领域问答。
- 输入：用户问题（如"什么是用例图？"）
- 输出：概念解释 + 通俗案例 + 教材关联 + 实践建议

### 4.2 PPT 智能生成 Agent（辅助教学）
- 输入：如"生成《软件工程 UML 建模》90 分钟课程 PPT"
- 输出：PPT 大纲（首页/课程目标/知识讲解/案例分析/课堂互动/练习任务/总结）+ PPT 文件 + 讲课备注

### 4.3 教案智能生成 Agent（辅助教学）
- 输入：如"生成《用例图》教学设计"
- 输出：课程名称/教学目标/教学重点/教学难点/教学流程/教师活动/学生活动/课堂练习/课后任务

### 4.4 UML 智能建模 Agent（辅助设计·核心）
- 目标：自然语言需求 → AI 分析 → 生成 UML 模型 → 自动检查 → 输出图片
- 首期支持 3 类图：用例图 / 活动图 / 状态机图（均有教材详稿与权威校验表）
- 处理流程：图类型识别 → 需求理解 → 图生成（中间 JSON）→ PlantUML → 图片 → 分图校验规则引擎 + LLM 复核 → 定向迭代 → 输出

### 4.5 辅助实践能力（辅助实践）
- 教材 AI 素养专题共 **10 个任务章节、43 个 AI 互动点**（覆盖 13 类图），按"启发思考 / 审查校验 / 关系语义辨析 / 综合验证模拟"4 大类型落地；
- 统一方法论为**四步迭代法**：手工前置分析 → 初始提示词 → 系统化质检 → 定向迭代；
- 首期完整落地任务二（用例图）/任务六（活动图）/任务七（状态机图）三类互动点。

## 5. 与扣子版的关系（重要约束）

- 任总已有：扣子平台工作流（无代码）。
- v13：**全新自研 Python + LangChain 实现**，不依赖 v12 代码、不迁移扣子工作流。
- 扣子版仅作为**目标效果参考**（能生成 UML、能质检、能输出图片/链接），实现方式完全自主。

## 6. 非目标（明确不做）

- 不做财务/学工等行政管理系统；
- 不做学生行为管理；
- 不替代教师线下授课，只做辅助工具；
- 不做手机原生 App（Web 优先）。

- RAG 问答可溯源到教材；
- 全部按 `01-规范与流程` 执行，文档与代码同步。
