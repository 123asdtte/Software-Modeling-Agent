# 技术选型方案（v13）

> 目标：为"AI教学智能体平台"选定稳定、可落地、可演示、成本可控的技术栈。
> 原则：不依赖 v12 代码、不迁移扣子工作流；扣子版只参考效果；**能复用开源就复用开源，不自造轮子**。
> 更新：2026-09-21，大模型定为 DeepSeek V4.1（用户提供 API Key）；RAG 底座复用开源 LightRAG。

---

## 1. 选型总表

| 层 | 选型 | 备选 | 说明 |
|---|---|---|---|
| 语言 | Python 3.11+ | — | AI 生态最成熟 |
| Web 框架 | FastAPI | Flask | 异步、自带 OpenAPI 文档 |
| AI 编排 | LangGraph | 纯 LangChain 链式 | 多 Agent 调度、状态机、可回放 |
| LLM 框架 | LangChain 1.x | LlamaIndex | RAG + Chain 生态成熟（venv 实测 1.4.2） |
| 大模型 | **DeepSeek V4.1**（`deepseek-flash`） | `deepseek-v4-pro` / 豆包兼容 | 用户提供 API，OpenAI 兼容，成本低 |
| Embedding | **BAAI/bge-m3（开源）** | 豆包 Embedding | DeepSeek 无官方 Embedding API；bge-m3 中文教材向量化效果佳 |
| RAG 引擎 | **LightRAG（开源，HKUDS）** | FAISS 自建 / RAGFlow | 复用开源检索增强引擎，底层 FAISS |
| 文档解析 | python-docx / pypdf / markdown | — | 教材（Word/PDF/MD）入库 |
| UML 渲染 | PlantUML（本地 jar，开源） | uml-mcp（MCP Tool） | 本地可离线，输出 PNG |
| PPT 生成 | python-pptx | — | 生成可编辑 .pptx |
| 用户存储 | SQLite（起步）→ PostgreSQL | — | 会话、练习记录 |
| 前端 | 轻量 Web（FastAPI 静态页 / Streamlit） | Next.js | 演示优先，后期可升级 |
| 部署 | Docker + Nginx | 裸机 | 校内服务器/教师机可跑 |

## 2. 大模型选型

| 维度 | 选择 | 理由 |
|---|---|---|
| 主模型 | **DeepSeek V4.1**（模型名 `deepseek-flash`，对应 DeepSeek-V4.1-Flash） | 用户提供 API Key；中文教学效果好、成本低、OpenAI 兼容 |
| 接口 | OpenAI 兼容格式，Base URL `https://api.deepseek.com`，Bearer Token 认证 | 直接复用 langchain-openai 生态 |
| 高配备选 | `deepseek-v4-pro`（DeepSeek-V4-Pro-0813） | 复杂推理/质检复核场景可切换 |
| 备用通道 | 豆包 / 其他 OpenAI 兼容模型（通过 llm.py 工厂切换） | 抽象统一，防止绑定 |
| 参数 | 长文本场景 max_tokens 调大；教学回答 temperature 0.3 左右 | 稳、少随机 |
| 调用 | 统一走 `app/models/llm.py` 工厂 | 一处切换，全局生效 |

**模型抽象要求**：所有 Agent 不直接依赖具体模型，通过 `llm.py` 获取；支持"DeepSeek/兼容模型"多通道，便于演示时切换。

**API Key 管理**：写入本地 `.env`（已加入 `.gitignore`），`pydantic-settings` 读取；代码与文档一律用占位符 `${DEEPSEEK_API_KEY}`，禁止硬编码（见 `01-规范与流程/02_编码与命名规范.md` 第 5 节）。

## 3. RAG 选型（复用开源）

- **引擎**：**LightRAG**（HKUDS 港大开源，`pip install lightrag-hku`）——纯 Python 库级集成、轻量免部署服务、与 LangChain 生态兼容，内置 FAISS 向量存储与增量索引、混合检索；规模化可切 Milvus 或 RAGFlow。
- **文档解析**：教材 Word → python-docx 分块；PDF → pypdf 按页/章节分块；保留章节标题作为元数据（自研 `document_reader` 负责解析与元数据）。
- **分块策略**：按"章节 → 小节 → 段落"语义分块，块大小 300–500 字，重叠 50 字，保留标题层级。
- **向量化**：Embedding 模型统一用 **BAAI/bge-m3**（开源中文向量模型）；向量维度记录在配置。
- **检索**：LightRAG 向量 + 关键词混合检索 → 取 top-3 作为上下文；回答必须带来源标注（教材章节/校验表号）。
- **存储**：FAISS 本地索引 + 元数据 JSON（来源/章节/页码），可重建。

## 4. UML 渲染选型（复用开源）

- 首选：**PlantUML 本地服务**（java -jar plantuml.jar，可离线、稳定、开源）；
- 可选能力：**uml-mcp**（开源 MCP Server，自然语言→UML/Mermaid）作为 Agent Tool 挂载，增强生成层；
- 备选：Draw.io XML（参考扣子版效果，生成 drawio 源 + 在线预览）；
- 输出：PNG 图片（供 PPT/教案/作业嵌入）+ 源码（可复制）。

## 5. 多智能体编排（LangGraph）

- 图结构：一个"调度图"（supervisor）路由到 QA / PPT / 教案 / UML 四个 Agent 子图；
- 路由依据：意图识别（LLM 分类 or 用户显式选择）；
- 状态：共享消息状态，每个子图独立可测试；
- 可观测：LangSmith / 本地日志记录每步输入输出，便于评审与复盘。

## 6. 前端选型

- **v13 演示期**：FastAPI 提供接口 + 单页 Web（HTML/JS），或 Streamlit 快速搭演示界面；
- 页面：问答页 / 资源生成页（PPT·教案）/ UML 建模页（输入需求→图→审查）/ 演示页；
- 升级路径：后续可迁到 Next.js/教学平台嵌入（iframe 或 API 对接）。

## 7. 成本与资源

| 项 | 估算 | 备注 |
|---|---|---|
| 大模型 API | 按量，演示期可控 | DeepSeek 定价低；设置额度上限与限流 |
| PlantUML / LightRAG / bge | 本地运行，0 成本 | 开源自托管 |
| 向量库 | FAISS 本地 0 成本 | 教材规模（几十 MB 文本）足够 |
| 服务器 | 校内服务器或教师机即可 | CPU 可跑，GPU 非必需 |
