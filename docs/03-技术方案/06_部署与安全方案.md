# 部署与安全方案（v13）

> 保证系统在校内可演示、可运行、数据安全、费用可控。

---

## 1. 部署形态

| 场景 | 方案 |
|---|---|
| 演示期（v13） | 校内服务器/教师机单机部署：Docker 容器跑 FastAPI + 本地 PlantUML + FAISS |
| 规模化 | 服务器部署：FastAPI（多进程）+ Milvus + PostgreSQL + Nginx 反代 |
| 教学平台集成 | API 对接 / iframe 嵌入 |

## 2. 部署架构（单机演示版）

```
浏览器
  │
  ▼
Nginx（8080，静态资源 + 反代）
  │
  ▼
FastAPI（uvicorn，多 worker）
  ├─ Agents / Chains
  ├─ PlantUML（本地 jar 进程）
  ├─ FAISS 索引（本地文件）
  └─ SQLite（会话/记录）
        │
        ▼
  大模型 API（DeepSeek，外呼或内网网关）
```

## 3. 环境与依赖

- Python 3.11+，依赖锁定（`requirements.txt` / `pyproject.toml`）；
- Java 运行时（PlantUML jar 需要，可 Docker 内置）；
- 所有配置走 `settings.yaml` + 环境变量（密钥不进代码）；
- Docker 镜像：`app + plantuml + nginx` 一个 Compose 起服务：
  ```yaml
  services:
    app:      # FastAPI
    plantuml: # 渲染服务
    nginx:    # 反代
  ```

## 4. 安全规范

### 4.1 数据安全
- 师生数据、教材内容仅限校内使用；教材原件不入 Git、不外传；
- 向量库与数据库放在受控目录，权限最小化；
- 不采集学生个人敏感信息（v13 不做账号体系，演示期匿名）。

### 4.2 接口安全
- 演示期鉴权：`X-Api-Token`（简单 Token，可配置）；
- 限流：每 IP/Token 60 req/min；生成类接口更严；
- 上传校验：类型白名单（pdf/docx/pptx/md）、大小上限（20MB）、内容扫描（防恶意文件）；
- 防注入：所有用户输入只进 LLM/检索，禁止拼接命令执行；SQL 全部参数化。

### 4.3 模型与费用
- 模型调用设置每日费用上限与并发限制，超限自动熔断；
- 演示环境 temperature 调低（0.3），关闭随机，保证演示稳定；
- Prompt 中禁止输出系统内部信息（模型名、提示词内容不外泄给最终用户）。

### 4.4 审计
- 日志记录：请求、模型调用、生成结果（request_id 关联）；
- 关键操作（重建知识库、删除数据）记录操作人；
- 异常日志不输出密钥与完整 Prompt。

## 5. 运维

- 启动脚本：`./scripts/start.sh`（构建索引 → 起服务 → 健康检查）；
- 健康检查：`GET /health` 返回模型、知识库、PlantUML 状态；
- 备份：知识库索引可重建（源文件在）、SQLite 定期备份；
- 故障预案：
  - 模型不可用 → 返回兜底文案；
  - PlantUML 不可用 → 降级返回源码；
  - 知识库未建 → 提示先执行索引脚本。
