# RAG 知识库设计方案（v13）

> 服务于智能问答 Agent，并为 PPT/教案/UML 提供教材依据。核心目标：**回答可溯源、检索高质量、教材可更新**。
> 更新：2026-09-21，新增"教材源稿首批入库清单"。

---

## 1. 知识库内容范围

| 数据源 | 格式 | 用途 |
|---|---|---|
| 软件建模教材（主） | Word / PDF | 问答依据、UML 教学规范 |
| **教材源稿 · AI素养专题（首批）** | MD（docx 提取） | **智能问答核心教材 + 43 个 AI 互动点提示词素材 + UML 校验表依据** |
| 课程资料 | PPT / MD / PDF | 授课补充 |
| UML 建模规则文档 | MD | 质检规则依据（可人工维护） |
| AI 互动教学设计 | MD | 辅助实践场景 |

> 教材原件按授权入库，不进 Git（见 Git 规范）。教材源稿的 docx 原件存于项目外微信临时目录，正文提取稿已落盘 `02-需求文档PRD/_教材源稿提取/` 供入库与查阅。

**入库要求**：

- 校验表转 Markdown 表格后独立分块，元数据标注 `{source: 教材源稿, chapter: 任务X, table_ref: 表2-4}`；
- 互动点参考提示词单独成块，便于问答与 Agent Prompt 检索复用。

## 3. 入库流程

```
教材文件（docx/pdf/md，首批为教材源稿 MD）
  ↓ document_reader 解析（保留章节结构）
  ↓ 语义分块（块 300–500 字、重叠 50 字、带标题元数据）
  ↓ Embedding 向量化（BAAI/bge-m3 开源模型）
  ↓ LightRAG 索引（开源引擎，内置 FAISS + 增量索引 + 混合检索）
  ↓ 生成知识库清单（版本 / 覆盖章节 / 入库时间）
```

## 4. 分块策略

- 按教材目录结构分块：任务章节 → 节 → 互动点 → 段落；
- 块大小：300–500 字，重叠 50 字（避免跨块语义断裂）；
- 每块元数据：`{source, chapter, section, page, heading, table_ref}`；
- 表格/图例单独处理（表格转 Markdown 表格后入库，校验表保留表号引用）。

## 5. 检索链路

```
用户问题
  ↓ 向量化（同一 Embedding 模型）
  ↓ top-k 召回（k=10，余弦相似度）
  ↓ 可选混合检索（BM25 + 向量，提高召回）
  ↓ 重排取 top-3
  ↓ 组装上下文（保留元数据用于引用标注）
  ↓ LLM 生成回答（必须引用来源）
```

**引用格式**：回答中以"（教材《软件建模技术教材·AI素养专题》任务 X · 互动点 Y）"或"（教材校验表 2-4）"标注，前端可跳转。

## 6. 评测指标（RAG Eval）

| 指标 | 定义 | 目标 |
|---|---|---|
| 检索命中率@3 | top-3 是否含答案来源 | ≥ 90% |
| 回答正确率 | 人工评分 | ≥ 85% |
| 引用可追溯率 | 回答是否都带来源 | 100% |
| 无命中兜底率 | 未命中时是否正确兜底 | 100% 不编造 |

- 评测集：`tests/fixtures/qa_cases.json`（≥30 问，覆盖概念/案例/互动点提示词/边界）；
- 每次改知识库或检索链路后回归。

## 7. 知识库维护

- 教材更新 → 重新解析对应章节 → 增量重建索引（FAISS 按 source 隔离，可局部重建）；
- 提供"重建脚本"：`python -m app.knowledge_base.build --source textbooks --force`；
- 版本记录：知识库版本号随教材版本变更，问答结果标注所用版本。

## 8. 向量库选型落地（复用开源）

| 阶段 | 方案 | 说明 |
|---|---|---|
| 起步（v13） | **LightRAG**（HKUDS 开源，`pip install lightrag-hku`） | 纯 Python 库级集成，免部署服务；内置 FAISS 存储与增量索引、向量+关键词混合检索；与 LangChain 生态兼容 |
| 规模化 | Milvus / RAGFlow | 多教材/多年级/百万级块 |

- Embedding 模型：**BAAI/bge-m3**（开源中文向量模型）；维度、模型名写入 `settings.yaml`；
- 索引持久化目录：`app/knowledge_base/embeddings/`（Git 忽略，可重建）；
- 替换成本：LightRAG 接口统一封装在 `app/knowledge_base/`，未来切 Milvus/RAGFlow 只改实现、不动上层。

## 9. 与其他模块的协作

- 智能问答：直接使用本 RAG，首批以教材源稿 KB-01~KB-04 为核心语料；
- PPT/教案：可选检索教材大纲/规范/互动点提示词，保证内容贴合教材；
- UML 质检：分图校验规则依据（教材校验表）放知识库（便于老师维护规则文案），规则引擎仍走代码实现（见 `03-技术方案/04_UML建模Agent详细技术方案.md` 第 4 节）。
