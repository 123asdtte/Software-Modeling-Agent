# AI教学智能体平台 v13

**基于 Python + LangChain 构建的教育领域多智能体系统**

> 定位：面向学校师生的智能教学助手，覆盖「辅助教学 / 辅助设计 / 辅助实践」三个方向。
> 版本基线：v13（全新自研）。**不依赖 v12 代码，不迁移扣子工作流**；扣子平台已有工作流仅作为目标效果参考。

---

## 一、项目一句话

让 AI 从"回答问题"升级为"教学助手"：为教师提供备课/教案/PPT/教学设计的生产力工具，为学生提供知识学习、即时答疑与软件建模实践的训练助手。

## 二、三大能力方向

| 方向 | 模块 | 说明 |
|---|---|---|
| **辅助教学** | 智能问答 Agent | 基于教材知识库，为师生提供专业领域问答（概念解释/通俗案例/教材关联/实践建议） |
| **辅助教学** | PPT 智能生成 Agent | 输入课题一键生成 PPT 大纲、PPT 文件、讲课备注 |
| **辅助教学** | 教案智能生成 Agent | 输入课题生成完整教学设计（目标/重点难点/流程/师生活动/练习/作业） |
| **辅助设计** | UML 智能建模 Agent（核心） | 自然语言 → 需求分析 → UML 生成 → 智能审查 → 图片输出 |
| **辅助实践** | 教材 AI 互动点体系 | 10 任务章节 · 43 个互动点（启发思考/审查校验/关系辨析/综合验证）· 四步迭代法，落地到学生建模训练 |

## 三、教材侧重点

AI 辅助**软件建模教学**，覆盖教材《软件建模技术·AI素养专题》10 个任务章节、13 类图、**43 个 AI 互动点**，统一方法论为**四步迭代法**（手工前置分析 → 初始提示词 → 系统化质检 → 定向迭代）。

互动点归纳为 4 大类型：

1. **启发思考** —— 需求/概念阶段先引导提问，不直接给答案（反面案例 + 比喻建立认知）；
2. **审查校验** —— 按图类型校验：用例图（边界/粒度/关系）、活动图（泳道/粒度/控制逻辑）、状态机图（状态/复合状态/转换逻辑）；
3. **关系语义辨析** —— 包含 vs 扩展（删除测试）、依赖 vs 关联、分叉 vs 决策、状态 vs 动作、同步 vs 异步；
4. **综合建模双重验证** —— 分图规则校验 + 大模型复核，对生成模型做双重验证。

## 四、核心链路（UML Agent · 首期 3 类图）

```
用户自然语言需求（可指定：用例图 / 活动图 / 状态机图）
      ↓
图类型识别（用户指定 or LLM 意图识别）
      ↓
需求理解（LLM 按图类型分析：Actor/UseCase · 泳道/动作/控制逻辑 · 状态/转换）
      ↓
UML 生成（中间 JSON）
      ↓
PlantUML 转换
      ↓
图片生成
      ↓
智能审查（分图校验规则库 + LLM 复核双重验证）
      ↓
定向迭代（分条修改指令 → 重生成 → 再审查）
      ↓
最终输出（图 + 审查意见 + 迭代记录）
```

## 五、技术栈总览

| 层 | 选型 |
|---|---|
| 前端 | Web 展示页面（教学平台 / 演示用） |
| API 层 | FastAPI |
| AI 编排 | LangGraph（多 Agent 调度：QA / PPT / 教案 / UML） |
| 框架 | LangChain |
| 知识库 | RAG：教材 / PDF / 课程资料 → Vector DB（FAISS 起步 / Milvus 规模化） |
| 大模型 | DeepSeek V4.1 为主（可切换 OpenAI 兼容模型） |
